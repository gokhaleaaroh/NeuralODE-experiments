# NeuralODE-experiments
A set of experiments for testing the capabilities of Neural ODEs, a deep learning architecture capabale of continuous-time modeling of data.

## Van der Pol Oscillator
Neural ODEs can learn the dynamics of a Van der Pol oscillator by learning through ground truth trajectory samples. The resulting model is a surrogate for the true dynamics and mimics the true dynamics remarkably well.
